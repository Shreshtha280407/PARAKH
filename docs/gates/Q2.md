# Q2 technical evidence quality — amended functional gate

Status: **PASS — owner-amended functional scope implemented and verified locally** under the
[owner-approved master-plan amendment](../Q2_Q3_master_plan_amendment.md).
This gate covers real offline technical assistance on the supplied proxy collection,
not independent field-generalisation proof. Semantic task-target framing is unsupported.

`:assist-quality` implements bounded read-only Kotlin/Android photo/video analysis:
integer luma, dark/highlight fractions, interior population Laplacian variance and a
coherent tile-translation camera-motion proxy. Correct EXIF/container rotation, tiny/
corrupt inputs, missing configuration, cancellation and resource release are explicit.
Tiny images lacking a Laplacian interior now return PARTIAL/`blur_unavailable`, while
retaining usable exposure metrics. Native codec buffers and observed device memory are
reported; no whole-video/frame-tree/full-resolution bitmap processing is used.

The single bundled `quality-proxy-v2` profile records definitions, preprocessing and
provenance: dark mean<60; photo Laplacian variance<400; video variance<100; reliable
reduced-image camera translation>=2px. Motion uses1s anchors+125ms partners,9 textured
12px tiles at~80px, +/-4px search, +/-1px vector-neighbour consensus, median translation,
>=5 textured tiles, >=2/3 consensus and residual<=20. Fixed texture variance minimum25
and clipping Y<=16/Y>=235 are metric-definition constants. Saturation mean>245 and
highlight fraction>0.95 is an engineering guard with synthetic verification only; the
proxy collection has no validated real positive overexposure cases.

Original Out_of_frame samples/annotations remain. Their technical metrics are evaluated
normally; missing a task target alone is not a technical defect. Hand presence never
substitutes for framing. Proxy household/MCB/switch footage is not trade competence validation.
