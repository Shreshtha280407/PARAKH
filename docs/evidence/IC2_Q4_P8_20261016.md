  fixed it. A subsequent model initialization probe exposed protobuf-reflected fields removed
  by R8; narrow MediaPipe callbacks plus GeneratedMessageLite field preservation fixed real

  the host now requires positive analysed sample counts from both engines.

  lifecycle transitions before Activity close. **Fresh v2 seal passed**, not merely a replay
